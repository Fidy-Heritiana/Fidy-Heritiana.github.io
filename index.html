Analysis of algorithms · Analytic combinatorics · Statistical data analysis

PhD in Mathematics — Université de Fianarantsoa & Université de Montpellier.

I study how the structure and distribution of data influence the behaviour of algorithms. My research combines mathematical proofs, generating functions, combinatorial models and computational experiments. Here I share research code, data and interactive demonstrations to help others explore and reproduce the results.

Interactive research projects

Quicksort under the Mallows distribution

Explore how an input distribution affects the number of comparisons made by first-pivot Quicksort. Compare finite-size means and variances with simulations, and inspect moment convergence and normal approximations.

Try the Quicksort demo · Source code and documentation · Citable software release

Greedy construction of oriented hierarchies

Investigate a greedy algorithm for constructing oriented hierarchies, a classification model used in statistical implicative analysis. Explore parameter sensitivity and compare running times.

Try the greedy-algorithm demo · Source code and experiments · Citable software release

Comparing Gras's algorithm with an optimized algorithm

Compare two methods for constructing oriented hierarchies on simulated data. This project accompanies the study published in Annals of Mathematics and Artificial Intelligence.

Try the algorithm-comparison demo · Source code and datasets · Research article · Citable software release

Reproducing and citing the work

Each project links to its code and documentation. For the featured software, the Zenodo links identify archived releases. When reproducing an experiment, record the release or commit, parameters and random seed, and use the citation information provided in the corresponding repository.
